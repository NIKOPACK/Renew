# 课程格式

课程用纯文本写成（UTF-8 的 `.txt`），一门课可以分成多个文件。`content/learn.txt` 是一个完整的示例。

## 结构

```text
@course learn | 学习的科学 | #3461f0 | 示例课程 | 一句话简介
@chapter learn1 | 第1章 记忆是怎么消失的
@section 1.1 遗忘曲线
（卡片……）
@practice
（本节练习题……）
@section 1.2 间隔重复
……
```

| 指令 | 说明 |
|---|---|
| `@course id \| 标题 \| 颜色 \| 分类 \| 简介` | 开始一门课。`id` 用小写字母和数字，全局唯一 |
| `@course id` | 单独一行：在另一个文件里续写已有的课程 |
| `@chapter id \| 标题` | 开始一章。`id` 一般为「课程 id + 章号」，如 `learn1` |
| `@section 标题` | 开始一节。节的 id 自动生成为「章 id + s + 序号」，如 `learn1s1` |
| `@practice` | 之后的题目是本节练习（「练习」步骤）；之前的题目是穿插在知识点之间的随堂小测。一节没有 `@practice` 时，所有题目都算练习 |

课程的显示顺序按文件名排序后首次出现的顺序，可以用文件名前缀控制（如 `1-xxx.txt`、`2-yyy.txt`）。

## 卡片

每张卡片以 `::类型` 开头，到下一张卡片或下一个指令为止。标题后可以加 `★`（0~3 个）表示重要程度，两颗星及以上会显示「高频」。`??` 之后的所有内容是详细解答。

### 知识点 `::kp`

```text
::kp 标题 ★★
- 要点 1（3~6 行，必须记住的结论）
- 要点 2
---
详解：原理、推导、例子、易错点……
```

### 单选 / 多选 `::choice` / `::multi`

```text
::choice ★★
题干
A. 选项
B. 选项
C. 选项
D. 选项
= B
?? 详细解答：为什么选 B，其他选项错在哪里
```

多选题的答案行写成 `= ABD`。

### 判断 `::tf`

```text
::tf
命题
= 对
?? 解答
```

### 问答 `::qa`

```text
::qa
问题
---
答案
?? 补充说明
```

### 填空 `::cloze`

```text
::cloze
遗忘的速度是先{{快}}后{{慢}}。
?? 解答
```

### 思考 / 计算题 `::think`

适合需要推导的题目，在手机上一步步展开提示：

```text
::think 标题
题目
>> 第 1 步提示
>> 第 2 步提示
= 结论
?? 详细解答
```

## 正文语法

正文是精简的 Markdown：

- `**粗体**`、`*斜体*`、`==高亮==`、`` `代码` ``、列表（可以缩进两格写二级列表）、表格
- 公式：行内 `$...$`，独立公式 `$$...$$`（KaTeX）
- 代码块：` ``` `
- 图示：用下面的作图代码块（plot / graph / tree / cells / seq），App 会画成跟随主题配色的矢量图（离线可用）。不要用字符拼画示意图；旧的 ` ```diagram ` 仍按等宽文字显示
- 提示块：

```text
> [!analogy] 打个比方
> 内容……
```

提示块类型：`analogy` 打个比方、`example` 例题、`warn` 易错、`exam` 怎么考、`tip` 技巧/口诀、`why` 为什么、`key` 重点、`note` 注意。

## 编译与导入

- 编译进 App：放在 `content/` 下，或放在仓库外并设置 `RENEW_CONTENT=目录`，然后 `npm run build`
- 导入到已安装的 App：在「资料」页导入 `.txt` 文件
- 编译器：`scripts/build_content.py` 会检查格式（例如题目缺少答案或解答时报错）

## 卡片 id 与复习记录

卡片 id 由「节 id + 类型 + 标题（没有标题时取第一行）」计算得到。修改正文、选项、解答不会影响已有的复习记录；修改标题或第一行会被当作一张新卡片。

## 课程包（`.renew.json`）

App 里「导出课程包」生成的 JSON，可以分享给别人导入：

```json
{
  "format": "renew-course",
  "v": 1,
  "course": {
    "id": "learn", "title": "学习的科学", "cat": "示例课程", "color": "#3461f0", "desc": "……",
    "chapters": [
      { "id": "learn1", "title": "第1章 ……", "sections": [
        { "id": "learn1s1", "title": "1.1 ……", "items": [
          { "t": "kp", "title": "……", "q": "要点", "d": "详解", "imp": 2 },
          { "t": "choice", "q": "题干", "o": ["A", "B", "C", "D"], "a": 1, "x": "解答", "pr": 1 }
        ] }
      ] }
    ],
    "cards": [
      { "type": "count", "title": "期末考试", "date": "2026-12-20", "pos": "top" },
      { "type": "ai", "title": "每日一句", "prompt": "一句英文名言，附中文翻译", "pos": "feed" }
    ]
  },
  "progress": {}
}
```

`t` 为卡片类型；`q` 题干或要点；`d` 详解；`o` 选项；`a` 答案（单选为序号，多选为序号数组，判断为布尔值，问答为文本）；`x` 解答；`st` 思考题步骤；`imp` 重要程度；`pr: 1` 表示本节练习。`cards` 为可选的「卡片」分支（显示在首页）：`type` 为 `text`（文字，内容写在 `body`）、`count`（倒计时，`date`）或 `ai`（每天由 AI 按 `prompt` 生成），`pos` 为 `top` 置顶或 `feed` 穿插在学习流里；更新已有课程时，同类型同标题的卡片就地更新，用户自己加的卡片保留。`progress` 为可选的学习进度。改名前「学流」导出的 `xueliu-course` 课程包同样可以导入。

## 作图

在知识点、解答、笔记和 AI 回答里都可以使用。点开任意一张图可以全屏查看：双指缩放、拖动、双击放大，矢量图放大后依然清晰。AI 写成 Mermaid 的流程图（`flowchart` / `graph`）、时序图（`sequenceDiagram`）和饼图（`pie`，显示为柱状图）也会自动转换显示。语言名决定图的种类，写错时会显示源文本和错误原因。

### plot：函数图像、数据折线、柱状图

````
```plot
x 0..30 天                    # 横轴范围与名称
y 0..100 记住的比例(%)         # 纵轴（不写则自动）
f 100*exp(-x/1.5) | 不复习     # 函数，变量 x；| 后是图例名
f 100*exp(-(x-1)/4) @1..5     # @a..b 限定定义域；没有名字时接着上一条画（分段函数）
p (1,1) (2,2) (3,4) 名称       # 数据点连线（s 开头为阶梯线）
h 8 ssthresh                  # 水平参考线；v 9 超时 为竖直参考线
xt off                        # 隐藏横轴刻度（yt off 隐藏纵轴刻度，grid off 去掉网格）
t (5,60) 文字                  # 标注
```
````

函数支持 `+ - * / ^`、`sin cos tan exp ln log log2 sqrt abs min max floor ceil` 和常数 `pi e`，`2x` 这样的隐式乘法也可以。柱状图单独一行：`bar O(1):1 | O(n):8 | O(n²):64`。

### graph：流程图、状态图、有向图、无向带权图

````
```graph
dir TB                        # TB 从上到下（默认），LR 从左到右
A(开始) -> B[读入 x] -> C{x > 0?}
C -> D[输出 正数] : 是          # 冒号后是边上的文字或权值
C -> E[输出 非正数] : 否
D -> F((结束))
E -> F
```
````

节点形状：`[方框]`、`(圆角)`、`((圆))`、`{菱形}`，节点后加 `*` 高亮。边：`->` 有向、`--` 无向、`<->` 双向、`-.->` 虚线。全是无向边时自动用环形布局（`layout circle` / `layout layer` 可指定）。

### tree：树、二叉树

````
```tree
A
  B
    D
    -          # - 表示空孩子，用来区分二叉树的左右
  C *          # 结尾 * 高亮
  <1> E        # <文字> 写在连向该结点的边上（如哈夫曼编码）
```
````

### cells：数组、链表、栈、指令格式、栈帧

````
```cells
arr[数组]: 3 | 1 | 4 | 1 | 5 *     # * 高亮；>> 后写右侧注释
idx: auto                         # 下标
list: 1 | 2 | 3 | NULL            # 链表
ptr: 0=slow | 2=fast              # 指向上一行第 i 个格子（从 0 数）
arr[指令]: OP@4 | A1@4 | A2@8 >> 16 位    # @n 为宽度占比
stack: c | b | a                  # 栈，第一个是栈顶
col: 高级语言机器 => 编译 | 汇编语言机器   # 竖排格子，=> 后是右侧说明
arr[模式]: ~ | a | b               # ~ 为空白占位，用于错位对齐
text: 说明文字
```
````

### seq：时序图（协议交互）

````
```seq
客户端 -> 服务器 : SYN, seq=x
服务器 -> 客户端 : SYN, ACK, seq=y, ack=x+1
--- 连接建立 ---               # 分隔线
客户端 --> 服务器 : 虚线消息
note 客户端 : TIME-WAIT 2MSL   # 在某一方下方标注
```
````

### 交互增强：图内挖空与分步演进

任意一种作图都支持以下两种交互写法：

- **图内挖空**：把节点、格子、消息或标注中的关键内容写成 `{{答案}}`（如 `arr: 1 | {{2}} | 3` 或 `A -> B : {{SYN}}`），App 会自动盖上遮罩，点按即可原地翻开；放在 `::cloze` 填空卡里时，会与卡片的「显示全部答案」及 FSRS 评分联动。
- **分步演进**：在同一个作图代码块内用单独一行 `=== 步骤说明` 分隔多帧画面，App 会渲染成带「上一步 / 下一步」与进度点的可交互分步图示，适合展示算法过程、指针移动、树旋转或协议状态变化：

````
```cells
=== 第 1 步：初始状态
arr: 5 * | 2 | 4
ptr: 0=i
=== 第 2 步：交换后
arr: 2 | 5 * | 4
ptr: 1=i
```
````
